# Tên Dự Án Của Bạn

Mô tả ngắn gọn về dự án này làm gì và dành cho ai.

## Tính năng
- Tính năng 1
- Tính năng 2

## Cài đặt
Chạy các lệnh sau để cài đặt dự án:
```bash
git clone <url-repo>
cd <ten-thu-muc>
npm install
```

## Sử dụng
```bash
npm start
```

## Giấy phép
Dự án này được phân phối dưới giấy phép MIT.
